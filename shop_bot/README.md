# Бот-каталог для Telegram-магазина

Покупатель нажимает кнопки «пол → категория → размер → цена» и получает **настоящие посты из канала**
(с видео, описанием и ссылкой на WhatsApp), а не листает бесконечную ленту.

Продавцу ничего заполнять не нужно: бот сам разбирает каждый пост — пол, категорию, размеры
(приводит к российским: `M` → 46, «по факту 48» → 48, брюки `Size 32` → W32), цену со скидкой и пометку «продано».

## Возможности

**Покупатель**
- поиск кнопками; показываются только варианты, где что-то есть, с количеством;
- посты по 5 штук, кнопка «▶️ Ещё», новые сверху;
- «🔔 Сообщать о новинках» — бот сам пришлёт новый пост по этому фильтру; `/subs` — управление подписками.

**Продавец** (`/admin`)
- статистика: товары, покупатели, поиски, подписки и **что искали, но не нашли**;
- нераспознанные посты приходят с кнопками «Пол / Категория / Размеры» — исправление в 2 клика;
- «❌ Продано» — кнопкой или словом «продано» в посте (бот увидит правку);
- перенос старых постов: переслать их боту (до 100 за раз) или скриптом `tools/forward_history.py`.

## Запуск на Mac (≈10 минут)

### 1. Создайте бота
1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя и username.
2. Скопируйте токен вида `123456789:AAAA...`.
3. Узнайте свой Telegram ID: напишите [@userinfobot](https://t.me/userinfobot).

### 2. Установите и настройте
Нужен Python 3.9+ (проверка: `python3 --version`). Надёжнее поставить свежий с [python.org](https://www.python.org/downloads/).

```bash
git clone https://github.com/marattanirbergen01/pp2_labs.git
cd pp2_labs
git checkout claude/using-100-3hizqe
cd shop_bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
open -e .env        # впишите BOT_TOKEN и ADMIN_IDS, сохраните
```

### 3. Запустите
```bash
python main.py
```
Пока окно терминала открыто и Mac не спит — бот работает (`caffeinate -dis python main.py`, чтобы Mac не уснул).
Остановить — `Ctrl+C`.

### 4. Наполните каталог — выберите один способ

**А. Переслать посты боту (проще всего).**
Откройте канал магазина, выделите посты (правый клик → Select) и перешлите своему боту.
Бот ответит сводкой: сколько добавлено и сколько нужно проверить.

**Б. Тестовый канал (как будет у настоящего магазина).**
1. Создайте свой канал, добавьте бота администратором.
2. Пересылайте туда посты — бот разберёт их сам. Новые посты в этом канале бот тоже подхватывает сам
   и рассылает подписчикам.

**В. Автоматически перенести посты за месяц (ничего не пересылая руками):**
1. На [my.telegram.org](https://my.telegram.org) → *API development tools* создайте приложение
   (название и адрес — любые), впишите `API_ID` и `API_HASH` в `.env`.
2. Запустите бота (`python main.py`) и во **втором** окне Терминала:
   ```bash
   cd ~/pp2_labs/shop_bot && source .venv/bin/activate
   pip install -r requirements-tools.txt
   python tools/forward_history.py --source "Dinara" --days 30
   ```
   При первом запуске скрипт спросит номер телефона и код из Telegram — введите их.
   Скрипт сам создаст канал «Каталог (тест)», сделает бота администратором и перешлёт туда посты
   за 30 дней. Бот пришлёт вам сводку: сколько товаров добавлено.
   Если в канале-источнике запрещена пересылка (защита контента), Telegram не даст переслать посты.

### 5. Проверьте
Напишите боту `/start` — как покупатель; `/admin` — панель продавца.

## Для настоящего магазина
Бот добавляется администратором в канал магазина (право «публиковать» не нужно, только чтение постов),
продавец пересылает старые посты боту один раз — дальше всё работает само.
Чтобы бот работал круглосуточно, его нужно разместить на сервере (VPS, Railway, Render и т.п.).

## Настройка под другой магазин
- `shopbot/categories.py` — категории, ключевые слова, таблица размеров, пороги цен.
- `.env` — название магазина, пол по умолчанию, сколько постов показывать за раз.

## Разработка
```bash
pip install -r requirements-dev.txt
pytest
```
Тесты прогоняют разбор реальных постов и сценарии целиком (канал → поиск → выдача → подписка → «продано»)
на поддельном Telegram.
